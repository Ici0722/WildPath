AI Use Statement

I used ChatGPT throughout the development of this project as a learning and debugging tool. Early in the project, ChatGPT helped me evaluate the feasibility of different APIs after I discovered that Movebank tracking data was not consistently accessible without login credentials or study-specific permissions. Based on this exploration, I decided to redesign the project around public iNaturalist observation data.

ChatGPT also helped me understand API documentation, troubleshoot errors, and generate example code snippets for Flask routes, API requests, Jinja templates, CSS styling, and Leaflet map integration. I used these examples as starting points and modified them to fit the requirements and goals of my project.

The final application design, bird species selection, filtering functionality, user interface decisions, testing, debugging, and project integration were completed by me. I was responsible for understanding, modifying, and validating all code included in the final submission, including the Flask application structure, urllib API requests, JSON data processing, and map visualization logic.
